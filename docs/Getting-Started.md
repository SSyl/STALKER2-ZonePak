# Getting started

This page builds the HelloZone example one step at a time, explains each file and command, and shows how to start a
mod of your own.

All commands run in a command prompt in the ZonePak folder, the folder from step 0 of the README's
[quick start](https://github.com/SSyl/ZonePak/blob/main/README.md#0-get-zonepak), as
`python -m zonepak [global options] <command>`. Global options such as `--project` and `--config` go before the
command. Always pass `--project`, because the current folder is the ZonePak folder, which is not a mod project. The
examples assume the config file from the quick start.

HelloZone changes one magazine and renames one item, so both kinds of content ZonePak builds are in one small mod.

## 1. Copy the example

Copy `examples\HelloZone` to a folder of your own, for example `C:\Mods\HelloZone`:

```
xcopy /E /I examples\HelloZone C:\Mods\HelloZone
```

You can also point `--project` at `examples\HelloZone` directly, but `build` then writes into the ZonePak folder.

## 2. Look at the three files

`zonepak.toml` names the mod:

```toml
name = "HelloZone"
friendly_name = "Hello Zone"
description = "ZonePak example: a 10-round PM magazine and a renamed Bandage"
version = "1.0"
database_id = "1793990000"
```

`name` becomes the mod's folder name in `~mods` and the start of every output file name. `database_id` names the
generated localization database.

`cfg/GameData/ItemPrototypes/HelloZone.cfg` patches the PM pistol's standard magazine:

```
GunPM_MagDefault : struct.begin {bpatch}
   Magazine : struct.begin {bpatch}
      MaxAmmo = 10
   struct.end
struct.end
```

`ItemPrototypes` is a binarized table, so the game reads any `.cfg` in that folder as a patch. `{bpatch}` on
`GunPM_MagDefault` and on its `Magazine` struct means only the listed field changes and everything else keeps its
vanilla value. Vanilla `MaxAmmo` is 8, which is the real Makarov PM's capacity. 10 is a demonstration change
that is easy to see in-game.

`text/en.toml` renames the Bandage in the English text:

```toml
sid_items_Bandage_name = "Bandage [HelloZone]"
```

## 3. Check

```
python -m zonepak --project C:\Mods\HelloZone check
```

```
0 error(s), 0 warning(s)
```

`check` reads the table list from the game's `pakchunk0-Windows.pak` and the vanilla structs from the Zone Kit,
then compares each patch against them. It also reads the `text/*.toml` files and reports the first one that
`build` would reject. `GunPM_MagDefault` exists in vanilla `ItemPrototypes` with its own `Magazine` struct, so
there is nothing to report.

## 4. Build

```
python -m zonepak --project C:\Mods\HelloZone build
```

```
built C:\Mods\HelloZone\build\HelloZone
```

The project's `build` folder now holds:

```
build/
  HelloZone/
    HelloZoneStalker2-Windows-OverrideContent.pak
    HelloZoneStalker2-Windows-OverrideContent.ucas
    HelloZoneStalker2-Windows-OverrideContent.utoc
  HelloZone-1.0.zip
  build.json
```

The `.utoc` and `.ucas` files hold the text, as the generated `Autogenerated_1793990000_LocalizationDatabase`
package. The `.pak` holds the cfg patch. A mod without text gets only the `.pak`.

## 5. Install

Copy the `build\HelloZone` folder into `<game>\Stalker2\Content\Paks\~mods\`, so that its three files are in
`~mods\HelloZone\`. After a rebuild, replace the whole folder, so that no file from the older build stays behind. To
uninstall the mod, delete `~mods\HelloZone`.

If a mod manager installed the same mod, disable that copy first. Vortex names its folder like
`~mods\AAJ-HelloZone ...`, and the game would load both.

## 6. Verify in-game

Start a new game, or load a save where you still have Skif's Pistol (`Gun_SkifGun_HG`). The player starts the
game with it, but it is a quest item, so a later save may not have it. It inherits `GunPM_HG` through `refkey` and
so uses the PM's standard magazine. You can also spawn a PM with `XCreateItemInInventoryByID GunPM_HG 0 1 1`,
which needs a console mod such as UE4SS. Reload, and the standard magazine holds 10 rounds instead of 8. A
magazine that was already loaded may keep 8 until it is unloaded and reloaded. With the game language set to
English, the Bandage is named `Bandage [HelloZone]`, unless you deleted `text\en.toml` to build without retoc.

## Exercise: break it on purpose

In your copy, change `MaxAmmo = 10` to `MaxAmo = 10` and run `check` again:

```
GameData/ItemPrototypes/HelloZone.cfg:3: error: GunPM_MagDefault.Magazine.MaxAmo does not exist in vanilla
1 error(s), 0 warning(s)
```

Each line gives the file relative to `cfg/`, the line number, the level and the message. `build` prints the same
line, then `error: 1 error(s) in patch or text files`, and leaves the previous build untouched. Fix the typo before
going on.

## Make your own

```
python -m zonepak --project C:\Mods new MyMod
```

This creates `C:\Mods\MyMod` with `zonepak.toml`, `cfg/GameData/`, `text/` and a `.gitignore` for `build/`. Its
`database_id` comes from the current time. Never reuse HelloZone's ID, or any other mod's, in a new mod. The game
finds a mod's text through a package named after this ID, so two mods with the same ID conflict. Keep the ID
unchanged once a mod is released.
