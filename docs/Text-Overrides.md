# Text overrides

This page covers replacing the game's text, and mods that combine text with cfg patches.

Put text in `text/<culture>.toml`, one `key = "text"` line per string. The key is the game's localization key, for
example `sid_items_Bandage_name`. [Text keys](Finding-SIDs-And-Text-Keys.md#text-keys) gives the key patterns for
item and upgrade names. The 18 cultures are:

`ar`, `zh-Hans`, `zh-Hant`, `cs`, `en`, `fr`, `de`, `it`, `ja`, `ko`, `pl`, `pt-BR`, `ru`, `sr`, `es`, `es-419`,
`tr`, `uk`

```toml
sid_items_Bandage_name = "Bandage [MyMod]"
"key.with.dots" = "Quoted, because TOML reads a bare dotted key as nested tables"
```

Files are UTF-8, and a BOM is accepted. A key can appear in several culture files, one text per culture.
[Text keys](Finding-SIDs-And-Text-Keys.md#text-keys) shows how to find a key with `python -m zonepak text`.

`build` needs `retoc` for text. It generates `Autogenerated_<database_id>_LocalizationDatabase`, converts it into
`<Name>Stalker2-Windows-OverrideContent.utoc` and `.ucas`, and checks that retoc is the patched build. A text-only
mod also gets a `.pak`, which is empty.

## Cultures you leave out

For a key the game has, the game shows its own text in every culture your text files leave out. This was checked in
game on 2026-11-14 with a key overridden only in Russian and Ukrainian, which showed the game's own text in English.
So you can override a key in English alone, and players in other languages keep the game's text.

`fill_game_text = true` in `zonepak.toml` makes `build` copy the game's text into those cultures anyway, or the
game's `en` text where the game has none for that culture. It changes nothing players see. It also freezes that
wording, so a game update that changes one of those texts does not reach players until you build the mod again.

A new key, one the game does not have, has no game text to fall back on, so players in a culture your text files
leave out see the raw key, such as `zp_new_key`. Add `copy_new_text = "<culture>"` to `zonepak.toml`, for example
`copy_new_text = "en"`, to give each of those cultures that culture's text.

`check` warns about every new key that is still missing a culture and lists the cultures. The same warning catches a
misspelled key, because a misspelled key is new to the game. `build` prints how many texts it filled.

## Combined cfg and text mod

Put patches in `cfg/` and text in `text/` in the same project. The build writes one `.pak`, `.utoc` and `.ucas`,
with the text in the `.utoc` and `.ucas` and the cfg patches in the `.pak`. HelloZone is a combined mod, and both
of its changes were verified in-game together on 2026-11-03.
